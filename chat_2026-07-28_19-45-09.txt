Assistant: OOPs stands for **Object-Oriented Programming**. It is a programming paradigm based on the concept of "objects," which can contain data and code.

2.  **Abstraction**: Hiding complex implementation details and showing only the necessary features of an object.
3.  **Inheritance**: A mechanism where a new class derives properties and behaviors from an existing class, promoting code reusability.
4.  **Polymorphism**: The ability of a message or function to be displayed in more than one form (e.g., method overloading or overriding).
